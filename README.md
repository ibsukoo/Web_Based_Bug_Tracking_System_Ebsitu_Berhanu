# 📌 Abstract

This project presents a **Web-Based Bug Tracking and Reporting System** designed to simplify how software teams report, track, and manage bugs in a centralized way.

In many small and medium development environments, bug tracking is still handled using emails, spreadsheets, or disconnected tools. This often leads to confusion, delayed fixes, and poor communication between team members.

To solve this, the system provides a simple web platform where users can report bugs, developers can fix them, and administrators can manage the entire process in one place. The system follows a **client-server architecture** with a MySQL database and a backend built using PHP or Node.js.

The goal is to make bug tracking **simple, fast, and easy to use** for development teams.

---

# 🎯 Objectives

* To develop a simple system for reporting and tracking software bugs
* To improve communication between developers, testers, and admins
* To manage bugs through their full lifecycle (Open → In Progress → Resolved)
* To implement role-based access control (Admin, Developer, Tester)
* To store and manage bug data in a structured database

---

# 🧩 System Features

* User login and authentication system
* Bug reporting and submission form
* Bug assignment by administrator
* Bug status tracking system
* Commenting and updates on bugs
* Simple dashboard for users and admins

# 📊 System Architecture

```id="arch01"
User (Browser)
      ↓
Frontend (HTML, CSS, JavaScript)
      ↓
Backend (PHP / Node.js)
      ↓
Database (MySQL)
```

📌 The system follows a simple client-server architecture where the frontend handles user interaction, the backend processes logic, and the database stores all bug-related data.
